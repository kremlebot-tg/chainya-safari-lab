# Чайня тестовая демонстрация оформления

Официальная статическая тестовая копия принадлежащего владельцу сайта Чайни. Размещена для сравнения отображения интерфейса на тестовом адресе.

Это демонстрация проекта: бронирование, отправка форм, вход, оплата и связь с рабочим backend отключены. Персональные данные не принимаются. Не используйте копию для записи или покупки.

Исходное оформление представлено в `current/`, включая русский, английский и китайский варианты. Клиентский код приложения удалён после формирования статического представления. Полноценная работа backend этой копией не проверяется.

Права на контент и изображения остаются у соответствующих правообладателей. Лицензии используемых шрифтов — `current/fonts/licenses/`.
